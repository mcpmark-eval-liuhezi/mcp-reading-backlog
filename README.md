# mcp-reading-backlog

Reading backlog for our literature review on the **Model Context Protocol (MCP)** — the open standard for connecting LLMs to tools and data.

The backlog is tracked as a nested list of GitHub issues:

- **Parent issue:** [#1 — MCP literature review backlog](https://github.com/mcpmark-eval-liuhezi/mcp-reading-backlog/issues/1)
- Each paper has its own `Read: <title>` issue, attached under the parent as a sub-issue.

Papers were sourced from the local arXiv mirror and Google Scholar.
